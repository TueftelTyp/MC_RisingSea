# 🌊 Rising Sea

**Rising Sea** is a Minecraft Fabric mod that gradually raises the sea level, flooding landscapes and challenging players to survive in an increasingly submerged world.

Build higher, adapt to rising waters, and survive the flood!

## Features

- **Rising Sea Level** – Automatically raises the sea level at configurable intervals.
- **Multiple Flood Modes** – Choose between realistic flooding, global water layers, and experimental tsunamis.
- **Tsunami Events** – Configure wave height, speed, frequency, and whether the sea level remains permanently elevated.
- **Customizable Settings** – Adjust flood intervals, water levels, maximum height, and performance limits.
- **Random Intervals** – Optionally trigger sea level increases after a random number of Minecraft days.
- **Boat Protection** – Optional automatic boat elevation to keep boats and their passengers above rising water.
- **Building Protection** – Enclosed structures are protected from direct flooding unless water can enter.
- **Multiplayer Support** – Server-side flood management with administrator commands.
- **In-Game Configuration** – Configure the mod through Mod Menu.
- **Status Display** – Get notified before the next sea level increase.
- **Languages** – English and German.

## Flood Modes

| Mode | Description |
|---|---|
| **Realistic** | Water gradually spreads through accessible areas. |
| **Layers** | The global sea level rises in configurable steps. |
| **Tsunami (Experimental)** | Simulated waves travel across the world with optional permanent sea level increases. |

## Configuration

Configure Rising Sea through **Mod Menu**, the configuration file, or administrator commands.

Example commands:

```text
/risingsea config
/risingsea setlevel 100
/risingsea mode realistic
/risingsea mode layers
/risingsea mode tsunami
/risingsea tsunami trigger
```

## Installation

1. Install the Fabric Loader for Minecraft 26.3.
2. Install Fabric API.
3. Place the Rising Sea `.jar` file in your Minecraft `mods` folder.
4. Launch Minecraft and configure the mod.

**Optional:** Install Mod Menu for convenient in-game configuration.

## Important Notes

- Tsunami functionality is experimental.
- Flooding permanently modifies world blocks and may affect existing builds.
- Always back up your world before using the mod.
- Large-scale flooding may impact server performance.
